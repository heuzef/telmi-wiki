# Outils de compression d'images

Si vous cherchez des outils pour compresser vos images, voici une sélection de sites et logiciels gratuits qui vous permettront de réduire la taille de vos fichiers sans trop perdre en qualité.

N'hésitez pas à contribuer pour actualiser cette liste pour aider les autres créateurs.

## Sites de compression d'images libres et gratuits

- [Caesium](https://saerasoft.com/caesium)
- [XL Converter](https://codepoems.eu/xl-converter)
- [OptiPNG](http://optipng.sourceforge.net)
